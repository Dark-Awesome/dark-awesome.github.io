# Meghanshu Verma — GitHub Pages profile

A static, dependency-free personal site in a Swiss / International Typographic Style-inspired layout.

## Publish on GitHub Pages

For a user site, GitHub Pages expects a repository named `<username>.github.io`. The resume lists the GitHub profile as `github.com/Dark-Awesome`, so the intended repository name is `dark-awesome.github.io`.

1. Create `dark-awesome.github.io` on GitHub.
2. Upload the contents of this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
5. Open `https://dark-awesome.github.io/` after GitHub Pages finishes publishing.

GitHub notes that publication can take up to about 10 minutes after changes are pushed.
